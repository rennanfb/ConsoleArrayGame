🎮 ConsoleArrayGame
A console-based game developed in C#, where the player must dodge incoming enemies. The goal is to survive as long as possible and achieve the highest score.

🕹️ How to Play
Use the following keys to control the player:

W — Move up
A — Move left
S — Move down
D — Move right
Avoid colliding with enemies to keep playing.

📊 Scoring
Your score increases continuously while the game is running.

As your score increases, enemies spawn more frequently and move faster, making the game progressively more challenging.

🛠️ Technologies
C#
.NET
Console Application
🚀 How to Run
Clone this repository:

git clone [<REPOSITORY_URL>](https://github.com/rennanfb/ConsoleArrayGame)
Navigate to the project directory:

cd ConsoleArrayGame
Run the game:

dotnet run
Have fun and try to achieve the highest score possible!
